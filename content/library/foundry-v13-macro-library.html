Path of the Giant — Rage Toggle

 v13 Macro

Path of the Giant

Один перемикач для повного Rage

Один макрос вмикає/вимикає Rage, витрачає використання тільки при ON, створює Active Effect на Actor, а при OFF видаляє його.

Вмикає й вимикає

Повторний запуск знаходить активний Rage effect і прибирає його.

Рахує використання

Збільшує system.uses.spent тільки під час активації.

Збільшує токен

ATL додає один крок ширини й висоти, щоб ефект складався з Enlarge.

У цій спрощеній схемі 1d6 Elemental Cleaver лишається без damage type, щоб не моделювати щоразу Acid/Cold/Fire/Thunder/Lightning. Це технічне спрощення, не RAW.

Перед запуском

Active Effect для Rage

Налаштуй effect у предметі Rage один раз; далі macro створює його копію на Actor.

  1. Встановити й увімкнути Active Token Effects 1.1.1.
  2. У Rage → Effects → Rage → Changes налаштувати рядки нижче.
  3. Для масштабування, яке нормально складається з Enlarge, використовувати Add +1, а не Override 2.

Foundry Macro

Rage Toggle

Виділи токен персонажа й запускай один і той самий macro для ON та OFF.

Rage Toggle.jsповний код
const token = canvas.tokens.controlled[0];

if (!token) {
  ui.notifications.warn("Спочатку виділи токен персонажа.");
  return;
}

const actor = token.actor;
const rageItem = actor.items.find(i => i.name.trim().toLowerCase() === "rage");

if (!rageItem) {
  ui.notifications.error("Не знайдено уміння Rage.");
  return;
}

const activeRage = actor.effects.find(e =>
  e.name.trim().toLowerCase() === "rage" && !e.disabled
);

if (activeRage) {
  await activeRage.delete();
  ui.notifications.info("Rage вимкнено.");
  return;
}

const remaining = Number(rageItem.system.uses?.value ?? 0);
const spent = Number(rageItem.system.uses?.spent ?? 0);

if (remaining <= 0) {
  ui.notifications.warn("Не залишилося використань Rage.");
  return;
}

const sourceEffect = rageItem.effects.find(e =>
  e.name.trim().toLowerCase() === "rage"
);

if (!sourceEffect) {
  ui.notifications.error("У Rage не знайдено Active Effect.");
  return;
}

const effectData = sourceEffect.toObject();
delete effectData._id;

effectData.disabled = false;
effectData.transfer = false;
effectData.origin = rageItem.uuid;

await rageItem.update({ "system.uses.spent": spent + 1 });

effectData.duration ??= {};
effectData.duration.startTime = game.time.worldTime;

if (game.combat) {
  effectData.duration.startRound = game.combat.round;
  effectData.duration.startTurn = game.combat.turn;
}

await actor.createEmbeddedDocuments("ActiveEffect", [effectData]);
ui.notifications.info(`Rage активовано. Залишилось: ${remaining - 1}`);

Magical Enlarge

Незалежне збільшення, що складається з Rage

Окремий ефект, незалежний від Rage. Rage додає +1 size step, Enlarge додає ще +1. Разом: 1×1 → 2×2 → 3×3.

Ще один size step

ATL.width і ATL.height додають по одиниці.

Не залежить від Rage

Effect має власну назву й окремо створюється або видаляється.

10 rounds

Макрос задає тривалість ефекту на десять раундів.

Стек розміру: звичайний токен 1×1 → Rage 2×2 → Rage + Enlarge 3×3.

const token = canvas.tokens.controlled[0];

if (!token) {
  ui.notifications.warn("Спочатку виділи токен персонажа.");
  return;
}

const actor = token.actor;
const ITEM_NAME = "Магічне збільшення (чуже)";
const EFFECT_NAME = "Магічне збільшення (чуже)";

const item = actor.items.find(i =>
  i.name.trim().toLowerCase() === ITEM_NAME.toLowerCase()
);

if (!item) {
  ui.notifications.error(`Не знайдено "${ITEM_NAME}".`);
  return;
}

const activeEffect = actor.effects.find(e =>
  e.origin === item.uuid || e.name.trim().toLowerCase() === EFFECT_NAME.toLowerCase()
);

if (activeEffect) {
  await activeEffect.delete();
  ui.notifications.info("Магічне збільшення вимкнено.");
  return;
}

const sourceEffect = item.effects.find(e =>
  e.name.trim().toLowerCase() === EFFECT_NAME.toLowerCase()
) ?? item.effects.contents[0];

if (!sourceEffect) {
  ui.notifications.error("У заклятті не знайдено Active Effect.");
  return;
}

const effectData = sourceEffect.toObject();
delete effectData._id;

effectData.disabled = false;
effectData.transfer = false;
effectData.origin = item.uuid;
effectData.duration ??= {};
effectData.duration.seconds = null;
effectData.duration.rounds = 10;
effectData.duration.turns = null;
effectData.duration.startTime = game.time.worldTime;

if (game.combat) {
  effectData.duration.startRound = game.combat.round;
  effectData.duration.startTurn = game.combat.turn;
}

await actor.createEmbeddedDocuments("ActiveEffect", [effectData]);
ui.notifications.info("Магічне збільшення активовано.");

Torch on Token ON/OFF

Перед запуском виділи хоча б один токен.

Torch on Token.jsповний код
const tokens = canvas.tokens.controlled;

if (!tokens.length) {
  ui.notifications.warn("Спочатку виділи хоча б один токен.");
  return;
}

const FLAG_SCOPE = "world";
const FLAG_ACTIVE = "torchMacroActive";
const FLAG_BACKUP = "torchMacroBackup";

for (const token of tokens) {
  const doc = token.document;
  const isTorchActive = doc.getFlag(FLAG_SCOPE, FLAG_ACTIVE);

  if (isTorchActive) {
    const backup = doc.getFlag(FLAG_SCOPE, FLAG_BACKUP);
    if (backup) await doc.update({ light: backup });
    else await doc.update({ "light.bright": 0, "light.dim": 0 });
    await doc.unsetFlag(FLAG_SCOPE, FLAG_ACTIVE);
    await doc.unsetFlag(FLAG_SCOPE, FLAG_BACKUP);
    continue;
  }

  const backup = doc.light.toObject();
  await doc.setFlag(FLAG_SCOPE, FLAG_BACKUP, backup);
  await doc.setFlag(FLAG_SCOPE, FLAG_ACTIVE, true);

  await doc.update({
    "light.bright": 20,
    "light.dim": 40,
    "light.angle": 360,
    "light.color": "#a2642a",
    "light.alpha": 0.7,
    "light.animation.type": "torch",
    "light.animation.speed": 2,
    "light.animation.intensity": 3,
    "light.animation.reverse": false
  });
}

ui.notifications.info("Світло факела перемкнено.");

if (!canvas.ready || !canvas.scene) {
  ui.notifications.warn("Спочатку відкрий сцену.");
  return;
}

if (!game.user.isGM) {
  ui.notifications.warn("Цей макрос призначений для GM.");
  return;
}

if (globalThis._torchPlacementHandler) {
  canvas.stage.off("pointertap", globalThis._torchPlacementHandler);
}
if (globalThis._torchPlacementKeyHandler) {
  window.removeEventListener("keydown", globalThis._torchPlacementKeyHandler);
}

ui.notifications.info("Клікни по карті, щоб поставити світло. ESC — скасувати.");

const cleanup = () => {
  if (globalThis._torchPlacementHandler) canvas.stage.off("pointertap", globalThis._torchPlacementHandler);
  if (globalThis._torchPlacementKeyHandler) window.removeEventListener("keydown", globalThis._torchPlacementKeyHandler);
  globalThis._torchPlacementHandler = null;
  globalThis._torchPlacementKeyHandler = null;
};

globalThis._torchPlacementKeyHandler = event => {

Vision 60 ft

Виділи один або кілька токенів і запусти macro.

Vision 60 ft.jsповний код
const MIN_VISION = 60;
const tokens = canvas.tokens.controlled;
if (!tokens.length) {
  ui.notifications.warn("Спочатку виділи хоча б один токен.");
  return;
}
let changedTokens = 0;
let changedActors = 0;
const updatedActors = new Set();
for (const token of tokens) {
  const doc = token.document;
  const currentRange = doc.sight.range;
  const tokenUpdate = { "sight.enabled": true };
  if (currentRange !== null && currentRange < MIN_VISION) {
    tokenUpdate["sight.range"] = MIN_VISION;
  }
  await doc.update(tokenUpdate);
  changedTokens++;
  const actor = doc.baseActor;
  if (actor && !updatedActors.has(actor.id)) {
    const prototypeRange = actor.prototypeToken.sight.range;
    const actorUpdate = { "prototypeToken.sight.enabled": true };
    if (prototypeRange !== null && prototypeRange < MIN_VISION) {
      actorUpdate["prototypeToken.sight.range"] = MIN_VISION;
    }
    await actor.update(actorUpdate);
    updatedActors.add(actor.id);
    changedActors++;
  }
}
ui.notifications.info(`Vision: ${changedTokens} токен(ів), ${changedActors} Prototype Token(ів). Мінімум ${MIN_VISION} ft.`);
