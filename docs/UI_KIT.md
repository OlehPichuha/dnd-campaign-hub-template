# UI kit кампанійного порталу

Усі сторінки використовують одну компонентну систему у двох споріднених режимах. Режим задається для матеріалу в адмінці; користувач не перемикає тему вручну.

## Спільна основа

- Єдина гарнітура: **Inter**. Вона використовується в заголовках, тексті, кнопках, таблицях і кодових підписах.
- Радіуси: 8 px для контролів, 12 px для карток, 18 px для модальних вікон.
- Мінімальна висота основної кнопки або поля: 42 px, на мобільному — 44 px.
- Анімації тривають 180 ms і використовують `cubic-bezier(.16,1,.3,1)`. Системне налаштування reduced motion вимикає їх.
- Кожна дія має hover, pressed і видимий keyboard focus. Доступ ніколи не позначається лише кольором.
- Автономні HTML-сторінки мають однакову верхню панель із логотипом, кнопкою повернення і назвою режиму.

## Реалізація

- `src/design-system.css` — компоненти React-порталу.
- `public/page-ui-kit.css` — спільна система для автономних HTML-сторінок.
- `worker/index.ts` — додає до HTML єдину верхню панель і потрібний режим.
