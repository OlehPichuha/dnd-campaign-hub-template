# Як зробити портал своїм

## Назва й обкладинки

Заголовки «Портал кампанії» та «Ваша кампанія» — заглушки. Їх можна знайти пошуком у `src/App.tsx`, `src/AuthGate.tsx`, `src/Library.tsx`, `index.html` і `worker/index.ts`. Для бічної обкладинки замініть `public/images/campaign-cover.svg` власним файлом і змініть шлях у `src/App.tsx`. Локальні обкладинки плиток лежать у `public/images/*-placeholder.svg`, відповідність розділам — у `src/Library.tsx`. Для бібліотечної плитки майстер також може задати власне HTTPS-зображення в адмінці; воно має пріоритет над заглушкою.

Посилання на книгу задається **окремо від зображення** через секрет Cloudflare `CAMPAIGN_BOOK_URL` (див. [DEPLOYMENT.md](../DEPLOYMENT.md)). Поки посилання немає, заглушку видно, але кнопка переходу не працює. Гравці бачать обкладинку без переходу.

## Власна мапа

Поточна `public/images/template-map.svg` — оригінальна умовна мапа-приклад. Вона векторна, тому залишається чіткою при наближенні. Позначки зберігаються в D1 як частки ширини та висоти мапи; на новому зображенні зі старими позначками їхні координати можуть уже не відповідати місцям. Замінюйте мапу до того, як почнете позначати свій світ.

Для **векторної** мапи замініть SVG і залиште `MAP_USE_TILES = false` у `src/mapTiles.ts`. Якщо нова мапа має інші пропорції, змініть там `MAP_WIDTH` і `MAP_HEIGHT` на відповідні числа з тим самим співвідношенням сторін. Сам масштаб перегляду, панорамування й розташування позначок після цього підлаштовуються автоматично.

Для **великої растрової** мапи (JPG) використовуйте нарізку на фрагменти: так телефон отримує лише видимі частини, а при збільшенні — детальніші фрагменти.

1. Покладіть власне зображення в `public/images/campaign-map-source.jpg`. Переконайтеся, що маєте право його використовувати й поширювати.
2. Дізнайтеся розмір зображення в пікселях і внесіть ширину та висоту в `MAP_WIDTH` і `MAP_HEIGHT` файла `src/mapTiles.ts`.
3. Установіть Pillow (`python -m pip install Pillow`) і запустіть `python scripts/build-map-tiles.py`. Скрипт створить `public/images/map-tiles/preview.webp` і фрагменти для кількох рівнів деталізації.
4. Змініть `MAP_USE_TILES` на `true` і задайте нове значення `MAP_ASSET_VERSION` у `src/mapTiles.ts`, наприклад `my-map-v1`. Так браузери завантажать нові фрагменти замість старих кешованих.
5. Відкрийте мапу на ПК і телефоні: перевірте краї, наближення, чіткість тексту та мітки. Якщо зміниться розмір зображення, перебудуйте фрагменти й знову змініть версію.

Лінійка показує **милі**. Число `MAP_MILES_PER_PIXEL` у `src/mapTiles.ts` визначає, скільки миль відповідає одному пікселю оригінальної мапи. Для прикладу значення умовне. Для своєї мапи виміряйте відому відстань між двома точками у пікселях і поділіть кількість миль на цю відстань. Якщо довжина 100 миль займає 500 пікселів, задайте `0.2`.

## Дані та доступ

У новій D1 спочатку немає партій, NPC, міток і записів майстра. Майстер додає їх через сайт. Три профілі персонажів у `migrations/0009_player_slots.sql` — нейтральні місця без адрес; імена й пошти можна змінити в адмінці. Новий власник указує свій `OWNER_EMAIL` як секрет Cloudflare. Пошта з Google сама по собі не дає доступу гравцю, поки майстер не додасть її в адмінці.

Готові HTML-довідники є в `content/library/`. Після змін цих файлів запустіть `npm run content:local` або `npm run content:remote` для **своєї** бази. Звичайна публікація коду не переписує HTML, який уже лежить у D1. Якщо не хочете певний довідник у власній кампанії, приберіть його плитку в адмінці; для шаблону всі перелічені довідники збережені.
