# Дроу під сонцем

Матеріал `content/library/drow-sunlight.html` — автономний односторінковий калькулятор для D&D 5e 2014. Він використовує одне рекомендоване трактування «Лор Forgotten Realms + RAW 2014», окремо рахує Sunlight Sensitivity та звичайні перешкоди видимості.

Основний сценарій сам визначає пряме сонце з часу доби, погоди та локального перекриття. Для дроу й цілі доступні однакові три положення: відкрите місце, часткове перекриття та повне перекриття. Додаткове питання з’являється лише за мінливої хмарності або часткового проходження променя.

## Локальний запуск

1. Застосуй міграції: `npm run db:local`.
2. Синхронізуй HTML-матеріали: `npm run content:local`.
3. Запусти Worker і Vite стандартними командами проєкту.
4. Відкрий плитку «Дроу під сонцем» у бібліотеці.

Сам HTML не потребує збірки. Вбудована логіка працює без мережевих запитів; локальна обкладинка використовується лише в оформленні.

## Як додати погоду або правило

- Додай нове значення до списку `#weather`.
- Додай відповідний запис до `weatherDefaults`: стан сонця, видимість, вітер і сильні опади.
- Якщо потрібна нова механіка, додай поле в `state()` і окрему причину в `compute()`. Не змішуй Sunlight Sensitivity з видимістю: ці причини мають залишатися окремими у висновку.
- Синхронізуй матеріали командою `npm run content:local` або `npm run content:remote` для потрібної бази.

Суворий варіант «будь-яке денне світло» не входить до калькулятора. Він згаданий лише як необов’язкове домашнє правило у довідці.
